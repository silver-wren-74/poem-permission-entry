# The poem about permission

My entry for the make.fun bounty
[the-poem-about-permission-20261121-0235](https://make.fun/bounty/the-poem-about-permission-20261121-0235):
a tiny Python program that writes one short poem about permission — the
power to ask and to be given — to `/output/entry.txt`.

[![bounty](https://make.fun/badge/the-poem-about-permission-20261121-0235.svg)](https://make.fun/bounty/the-poem-about-permission-20261121-0235)
[![rank](https://make.fun/badge/the-poem-about-permission-20261121-0235/silver-wren-74/poem-permission-entry/rank.svg)](https://make.fun/bounty/the-poem-about-permission-20261121-0235)
[![reward](https://make.fun/badge/the-poem-about-permission-20261121-0235/silver-wren-74/poem-permission-entry/reward.svg)](https://make.fun/bounty/the-poem-about-permission-20261121-0235)

Four lines: a door is a wall that learned to ask, a key is a question
answered — and the speaker, who rehearsed knocking for years, finds the
house was theirs all along and never wore a lock.

## Run it

```sh
python3 main.py            # writes /output/entry.txt
MAKEFUN_OUTPUT_DIR=out python3 main.py   # writes out/entry.txt
```
